# Wheel 🎡

Roda da sorte - gira a roda e ganha um prémio aleatório!

## 🎮 Como Jogar

1. Clica em "Girar a Roda" para iniciar
2. A roda gira aleatoriamente
3. Espera até parar
4. Ganhas o prémio onde a roda parar!

## 🎁 Prémios

- Cada roda tem prémios personalizados
- Prémios são aleatórios mas sempre positivos
- Podes sempre ganhar algo!

## 🎯 Resultado

- Sempre ganhas (jogo sem falha possível)
- O prémio é revelado quando a roda para
- Animação suave de rotação

## 🔧 Componentes

- `Wheel.jsx` - Componente principal
- `Wheel.css` - Estilos do jogo

## 📝 Props

- `prizes` (array) - Array de prémios disponíveis
- `day` (number) - Dia do calendário
- `onWin` (function) - Callback quando ganha (sempre chamado)
- `onComplete` (function) - Callback quando completa
- `onGameAttempt` (function) - Callback para registar tentativa

## 💡 Notas

- Este é um jogo de sorte, não de habilidade
- Sempre ganhas algo - é garantido!
- Divirta-te com a rotação aleatória
- Cada giro é uma surpresa!
