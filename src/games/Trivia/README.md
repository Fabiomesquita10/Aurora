# Trivia 🎯

Jogo "Isto ou Aquilo" versão casal - escolhe entre duas opções.

## 🎮 Como Jogar

1. Lê a pergunta "Qual preferes?"
2. Escolhe entre duas opções:
   - Opção 1 (esquerda)
   - Opção 2 (direita)
3. Clica na opção escolhida
4. Responde a todas as perguntas (geralmente 5)
5. Ganha se escolheres as opções "corretas" (preferências do casal)!

## 🎯 Objetivo

- Escolhe as opções que correspondem às preferências do casal
- Cada pergunta tem uma resposta "correta" baseada nas preferências
- Ganha se escolheres todas as opções corretas

## 📊 Progresso

- Vê quantas perguntas já respondeste
- Vê quantas acertaste
- Feedback visual após cada resposta

## 🔧 Componentes

- `Trivia.jsx` - Componente principal
- `Trivia.css` - Estilos do jogo

## 📝 Props

- `questions` (array) - Array de perguntas com 2 opções
- `day` (number) - Dia do calendário
- `onWin` (function) - Callback quando acerta todas
- `onComplete` (function) - Callback quando completa
- `onGameAttempt` (function) - Callback para registar tentativa

## 💡 Dicas

- Pensa nas preferências do casal
- Escolhe honestamente - não há resposta errada!
- As perguntas são sobre vocês dois
- Divirta-te escolhendo!
