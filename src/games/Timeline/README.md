# Timeline 📅

Ordena eventos cronologicamente na ordem correta.

## 🎮 Como Jogar

1. Vê os eventos desordenados
2. Arrasta os eventos para ordená-los cronologicamente
3. Coloca o evento mais antigo no topo
4. Coloca o evento mais recente no fundo
5. Quando estiveres confiante, submete!

## 📅 Ordenação

- Arrasta e solta eventos para reordenar
- Ordem: mais antigo → mais recente
- Podes reorganizar quantas vezes quiseres
- Visualização clara da ordem atual

## 🎯 Validação

- O jogo valida se a ordem está correta
- Quando estiver correto, ganhas!
- Se estiver incorreto, podes tentar novamente

## 🔧 Componentes

- `Timeline.jsx` - Componente principal
- `Timeline.css` - Estilos do jogo

## 📝 Props

- `events` (array) - Array de eventos com datas
- `day` (number) - Dia do calendário
- `onWin` (function) - Callback quando acerta a ordem
- `onComplete` (function) - Callback quando completa
- `onGameAttempt` (function) - Callback para registar tentativa

## 💡 Dicas

- Procura eventos com datas específicas
- Pensa na sequência lógica dos eventos
- Eventos sobre o relacionamento podem ser mais fáceis
- Se não souberes a data exata, usa a lógica!
