# Scrambled Sentence 📝

Ordena uma frase que está toda desordenada!

## 🎮 Como Jogar

1. Vê as palavras desordenadas
2. Clica nas palavras na ordem correta
3. As palavras aparecem na área de construção
4. Se cometeres um erro, podes limpar e começar de novo
5. Quando a frase estiver correta, submete!

## 📝 Construção da Frase

- Clica nas palavras para adicioná-las à frase
- Ordem de cliques = ordem na frase
- Podes limpar e recomeçar a qualquer momento
- A frase construída aparece em tempo real

## 🎯 Validação

- O jogo valida se a frase está correta
- Pontuação e capitalização são importantes
- Quando estiver correto, ganhas!

## 🔧 Componentes

- `ScrambledSentence.jsx` - Componente principal
- `ScrambledSentence.css` - Estilos do jogo

## 📝 Props

- `sentence` (string) - Frase correta (desordenada)
- `day` (number) - Dia do calendário
- `onWin` (function) - Callback quando acerta
- `onComplete` (function) - Callback quando completa
- `onGameAttempt` (function) - Callback para registar tentativa

## 💡 Dicas

- Procura a primeira palavra (geralmente começa com maiúscula)
- Identifica o sujeito, verbo e objeto
- Pensa na estrutura da frase
- Podes tentar várias vezes até acertares!
