# Quiz ❓

Jogo de perguntas de escolha múltipla sobre relacionamento.

## 🎮 Como Jogar

1. Lê a pergunta cuidadosamente
2. Escolhe uma das 4 opções de resposta
3. Clica em "Submeter" para confirmar
4. Responde a todas as perguntas (geralmente 5)
5. Ganha se acertares todas!

## 📊 Pontuação

- Cada resposta correta vale 1 ponto
- Score final = número de respostas corretas
- Para ganhar, deves acertar todas as perguntas

## ❓ Perguntas

- Perguntas sobre relacionamento e o casal
- 4 opções de resposta por pergunta
- Apenas uma resposta está correta
- Podes responder na ordem que preferires

## 🎯 Progresso

- Vê quantas perguntas já respondeste
- Vê quantas acertaste
- Progresso visual durante o jogo

## 🔧 Componentes

- `Quiz.jsx` - Componente principal
- `Quiz.css` - Estilos do jogo

## 📝 Props

- `questions` (array) - Array de perguntas com opções
- `day` (number) - Dia do calendário
- `onWin` (function) - Callback quando acerta todas
- `onComplete` (function) - Callback quando completa
- `onGameAttempt` (function) - Callback para registar tentativa

## 💡 Dicas

- Lê todas as opções antes de escolher
- Não te apresses - pensa bem na resposta
- Perguntas são sobre vocês - usa a tua memória!
- Se não souberes, tenta adivinhar - nunca se sabe!
