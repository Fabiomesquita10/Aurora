# Mini Riddles 🧠

Resolve 3 enigmas curtos sobre séries, filmes ou vocês.

## 🎮 Como Jogar

1. Lê o enigma cuidadosamente
2. Digita a tua resposta
3. Clica em "Submeter" ou pressiona Enter
4. Responde a todos os 3 enigmas
5. Ganha se acertares todos!

## 🧩 Enigmas

- Enigmas sobre séries populares
- Enigmas sobre filmes famosos
- Enigmas sobre o casal
- Respostas geralmente são palavras ou frases curtas

## 📊 Pontuação

- Cada enigma acertado vale 1 ponto
- Para ganhar, deves acertar os 3 enigmas
- Respostas são case-insensitive (maiúsculas/minúsculas não importam)

## 🎯 Validação

- O jogo valida automaticamente se a resposta está correta
- Podes submeter quando estiveres confiante
- Se estiver incorreto, podes tentar novamente

## 🔧 Componentes

- `MiniRiddles.jsx` - Componente principal
- `MiniRiddles.css` - Estilos do jogo

## 📝 Props

- `riddles` (array) - Array de enigmas com perguntas e respostas
- `day` (number) - Dia do calendário
- `onWin` (function) - Callback quando acerta todos
- `onComplete` (function) - Callback quando completa
- `onGameAttempt` (function) - Callback para registar tentativa

## 💡 Dicas

- Pensa fora da caixa
- Alguns enigmas têm trocadilhos
- Usa a tua cultura geral
- Se não souberes, tenta adivinhar criativamente!
